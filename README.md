# Task 27: Reading and Writing Excel Data

## Internship
**Organization:** Veda Technology  
**Domain:** Data Science  
**Task:** 27 – Reading and Writing Excel Data

## Objective
Learn how to read Excel worksheets using Pandas, inspect their structure, perform basic data cleaning and transformations, and export processed results.

## Tools and Technologies
- Python
- Pandas
- OpenPyXL
- Jupyter Notebook

## Programs Included
1. Creating an Excel file using Pandas.
2. Reading Excel data using `read_excel()`.
3. Inspecting Excel data using `head()`, `info()` and `describe()`.
4. Cleaning data by handling missing values and duplicates.
5. Filtering, sorting and exporting Excel data using `to_excel()`.

## Installation

```bash
pip install pandas openpyxl
```

## Key Functions Used

| Function | Purpose |
|---|---|
| `read_excel()` | Read Excel files |
| `to_excel()` | Write Excel files |
| `head()` | Display first rows |
| `info()` | Dataset information |
| `describe()` | Statistical summary |
| `drop_duplicates()` | Remove duplicates |
| `fillna()` | Handle missing values |
| `sort_values()` | Sort data |
